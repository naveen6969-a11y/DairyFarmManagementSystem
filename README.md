# 🐄 Dairy Farm Management System

A C# WinForms desktop application for managing dairy farm operations. Built with Visual Studio and SQL Server.

## Tech Stack
- C# (Visual Studio)
- SQL Server
- Metro Framework UI

## User Roles
- **Admin** — Manage employees, full access to all features
- **Employee** — Record milk production, sales, health records, breeding and finance

## Features
- Cow management
- Daily milk production recording
- Health and vet records
- Breeding and pregnancy tracking
- Milk sales management
- Income and expenditure tracking
- Dashboard with farm summary

## 🚀 Quick Run
1. Go to the [Releases](https://github.com/ProllyNaveen/DairyFarmManagementSystem/releases) tab
2. Download `DairyFarmMS_Setup.exe`
3. Run the installer
4. Open SSMS → Restore database using the `.bak` file from the Database folder
5. Make sure SQL Server is running
6. Launch from desktop shortcut ✅

## Default Login
| Role | Username | Password |
|---|---|---|
| Admin | admin | 1122 |
| Employee | employee | 1122 |

## Note
⚠️ SQL Server must be running before launching the app
⚠️ Windows Smart App Control may block installer on first run — temporarily disable it in Windows Security settings
